# Runbook: Proxmox vzdump Backup Restoration Drill

## Objective
Regularly test and validate backup archives generated by Proxmox VE vzdump and Proxmox Backup Server (PBS). Drills must prove that a container or virtual machine can be fully restored to operational readiness without causing IP collisions or data corruption in the production environment.

## Drill Frequency
- **Critical Production LXCs** (Home Assistant, Scrutiny): Monthly restoration test.
- **Stateful Databases** (Core Banking DB, PostgreSQL): Bi-weekly automated restore verification.
- **Firewall Appliance** (OPNsense VM 200 configuration): Monthly XML config restoration test.

## Safety Principles (No Production Collision)
1. **Isolated Restoration ID**: Test restores must use a temporary VMID/CTID in the `900–999` range.
2. **Network Disconnect**: Test instances must be restored with `--restore` and network interfaces set to disconnected or mapped to an isolated dummy bridge (`vmbr3`) to prevent IP collisions with active services.
3. **Automated Destruction**: Once verification tests pass, test instances must be promptly destroyed to free storage space.

## Step-by-Step Procedure

### 1. Locate the Latest Backup Archive
On Proxmox Node 1, inspect available backup archives stored on the local or NFS storage pool:
```bash
# List available vzdump archives on OMV NAS NFS storage:
pvesm list nas-backup | grep -E "vzdump-lxc|vzdump-qemu" | sort -k 2 | tail -n 10
```

### 2. Execute Test Restoration (Example: Home Assistant CT 100)
```bash
BACKUP_ARCHIVE=$(pvesm list nas-backup | grep "vzdump-lxc-100" | tail -n 1 | awk '{print $1}')
TEST_CTID=901

echo "Restoring $BACKUP_ARCHIVE to temporary test container $TEST_CTID..."
pct restore "$TEST_CTID" "$BACKUP_ARCHIVE" \
    --storage local-lvm \
    --unprivileged 1 \
    --ignore-unpack-errors 0

# Modify network config to prevent IP conflict:
pct set "$TEST_CTID" --net0 name=eth0,bridge=vmbr3,ip=10.99.99.10/24,gw=10.99.99.1
```

### 3. Start & Verify Test Instance
```bash
# Boot test container:
pct start "$TEST_CTID"
sleep 15

# Verify container process table inside:
pct exec "$TEST_CTID" -- ps aux | grep -E "homeassistant|python"

# Verify filesystem integrity:
pct exec "$TEST_CTID" -- df -h /
```

### 4. Teardown Test Instance
```bash
echo "Stopping and destroying test container $TEST_CTID..."
pct stop "$TEST_CTID"
pct destroy "$TEST_CTID" --purge
```

### 5. Automated Verification Script
Alternatively, run the automated drill helper script:
```bash
bash scripts/disaster-recovery/dr_vzdump_restore.sh
```

## Drill Log & Audit Sign-Off
Record each drill result in the infrastructure audit log:
- Date of drill
- Target backup archive name and checksum
- Restore duration (seconds)
- File integrity check: `PASS` / `FAIL`
- Sign-off engineer
